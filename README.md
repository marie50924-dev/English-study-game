# 英単語かるた ― EIGO KARUTA

日本の**かるた**で英単語を覚えるブラウザゲームです。
読み手が札を読み上げ、畳に散らばった取り札から正しい1枚を取る。
**読み上げ＝英語の発音**なので、遊びながら耳と意味が結びつきます。

小学生から大学生まで、4つの学年レベル・全267語を収録。
ビルド不要の静的サイト（HTML + CSS + JavaScript）で、`index.html` を開くだけで遊べます。

## かるたの流れ

1. 「三・二・一・はじめ！」（拍子木）
2. **読み札**が読まれる
   - **英語読み**… 英単語の発音が流れる → 意味の**日本語の札**を取る（`R` キーや🔊で聞き直し可）
   - **日本語読み**… 読み札に日本語が出る → **英語の札**を取る
   - **ミックス**… 札ごとに面が違い、読み方も札に合わせて変わる
3. 正しい札をタップすれば**一本**。早く取るほど高得点
4. 違う札を取ると**お手つき**（持ち札を1枚相手に渡し、少しのあいだ手が止まる）
5. 少し待つと**決まり字**（頭の1文字）のヒントが出る

## 遊び方（2種類）

| 遊び方 | 内容 |
|---|---|
| 🀄 **かるた対戦** | 十二枚勝負。相手も一定の速さで札を取りにくるので早い者勝ち。多く取ったほうが勝ち |
| ⏳ **ひとりかるた** | 60秒で何枚取れるか。取るたびに札が補充される |

**相手の強さ**は4段階：🧒 こども名人（約3.6〜5.4秒）/ 🧑 町内会の猛者 / 🎓 かるた部主将 / 👹 永世名人（約1.2〜1.9秒）。

## ゲーム性

- **速さがそのまま点数**に … 読まれてから取るまでが速いほどボーナス
- **連取り** … 続けて取ると倍率が上がる
- **お手つき** … 得点減点 ＋ 持ち札を相手に渡す（ひとりかるたは −3秒）
- **段位（XP）** … 得点に応じて段位が上がる
- **対戦成績** … 勝敗をブラウザに記録
- **最高得点** … 学年 × 遊び方ごとに保存

## 苦手な札の復習

取りそこねた札・お手つきした札は「苦手な札」に貯まります（ホーム画面、🔊 で発音確認可）。

- **苦手モード**をONにすると、その札だけが場に並びます（枚数が足りないときは通常の札で補います）
- ノーミスで取れた札はリストから自動的に外れます

## 発音について

- 英語読みは Web Speech API による読み上げです（音声ファイル不要）
- 札を取った瞬間にも英単語を読み上げます（設定でOFF可）
- 結果画面の 🔊 でいつでも聞き直せます
- 読む速さは3段階（ゆっくり / ふつう / はやい）
- 日本語の音声が入っていない環境では、日本語読みは札の文字のみで読み上げます
- 音声読み上げ非対応のブラウザでは英語読み・ミックスが選べなくなり、日本語読みで遊べます

## 動かしかた

```bash
# そのまま開く
open index.html

# もしくはローカルサーバーで
npx http-server -p 8080
# → http://localhost:8080
```

GitHub Pages にそのまま公開できます（Settings → Pages → Branch を選ぶだけ）。

## ファイル構成

```
index.html        画面の骨組み
css/style.css     和風のデザイン（畳・生成りの札・朱と金）
js/data.js        単語データ（学年別）・遊び方・読み方・相手の定義
js/storage.js     設定・最高得点・段位・戦績・苦手な札の保存（localStorage）
js/audio.js       読み上げ（Web Speech API）と効果音（拍子木・札を取る音）
js/game.js        かるた本体（読み・取り・お手つき・相手の思考・勝敗判定）
js/main.js        画面遷移と選択UI
```

## 札（単語）を追加・編集する

`js/data.js` の該当レベルの `words` に追記するだけです。

```js
{ en: 'curious', ja: '好奇心の強い' }
```

学年を増やしたい場合は `VOCAB` に新しいキーを足し、`LEVEL_ORDER` に並び順を追加してください。
相手の強さは `OPPONENTS` の `min` / `max`（ミリ秒）で調整できます。
