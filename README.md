# EIGO MATCH ― 英単語マッチングゲーム

小学生から大学生まで遊べる、**日本語と英語をマッチングさせる英単語ゲーム**です。
正解すると英単語を自動で読み上げるので、意味と一緒に発音も覚えられます。

ビルド不要の静的サイト（HTML + CSS + JavaScript）。`index.html` を開くだけで動きます。

## あそびかた

1. **レベルを選ぶ** … 小学生 🌱 / 中学生 ⚡ / 高校生 🔥 / 大学生 👑（全267語）
2. **モードを選ぶ**
   | モード | 内容 | 制限時間 |
   |---|---|---|
   | ⚡ マッチング | 左の日本語と右の英語をタップしてペアを消す。消すと新しい単語が補充される | 75秒 |
   | 🃏 神経衰弱 | 裏向きのカードをめくって日本語と英語のペアをそろえる（全4ステージ） | 90秒 |
   | ⏱️ スピードクイズ | 4択で答える。`1`〜`4` キーでも回答可。日本語→英語 と 英語→日本語 が混ざる | 60秒 |
3. **スタート！**

## ゲーム性

- **コンボ倍率** … 連続正解でスコアが最大2倍まで伸びる
- **ライフ ♥×3** … ミス3回でゲームオーバー
- **タイムボーナス** … 正解するたびに残り時間が少し回復。クイズのミスは −3秒
- **ランク判定** … S / A / B / C / D
- **プレイヤーレベル** … スコアに応じてXPが貯まり、ホームのレベルが上がる
- **ハイスコア** … レベル × モードごとに保存（ブラウザの localStorage）

## 発音について

- 正解した瞬間に英単語を読み上げます（Web Speech API / 音声ファイル不要）
- 結果画面の 🔊 ボタンでいつでも聞き直せます
- マッチングモードでは、自動発音をオフにしていても英語カードをタップすると発音します
- ホームの設定で「効果音」「自動発音」「読む速さ（ゆっくり / ふつう / はやい）」を切り替えられます
- 読み上げは Chrome / Edge / Safari で動作します。非対応のブラウザではゲーム部分のみ動きます

## 動かしかた

```bash
# そのまま開く
open index.html

# もしくはローカルサーバーで
npx http-server -p 8080
# → http://localhost:8080
```

GitHub Pages にそのまま公開できます（Settings → Pages → Branch を選ぶだけ）。

## ファイル構成

```
index.html        画面の骨組み
css/style.css     デザイン・アニメーション
js/data.js        単語データ（学年別）とモード定義
js/storage.js     設定・ハイスコア・XPの保存（localStorage）
js/audio.js       発音（Web Speech API）と効果音（Web Audio API）
js/game.js        ゲーム本体（3モード・スコア・タイマー）
js/main.js        画面遷移とUIの組み立て
```

## 単語を追加・編集する

`js/data.js` の該当レベルの `words` に追記するだけです。

```js
{ en: 'curious', ja: '好奇心の強い' }
```

学年そのものを増やしたい場合は `VOCAB` に新しいキーを足し、`LEVEL_ORDER` に並び順を追加してください。
